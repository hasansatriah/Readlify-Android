                          Mode Fokus 🔒

                          🔒 Lagi dikunci soalnya sesi Mode Fokus masih jalan. Kelarin dulu sesinya buat ubah ini.

                          Pilih medsos yang pengen kamu jauhin pas fokus. Ini pengingat, bukan blokir teknis beneran, jadi semua aplikasi (termasuk WhatsApp) tetep bisa dibuka kalau emang perlu. Bonus: kalau kamu ninggalin Readlify pas timer fokus lagi jalan, muncul notifikasi "Balik fokus, yuk!". Readlify cuma tau aplikasinya sendiri lagi dibuka atau nggak, bukan ngintip aplikasi lain.

                          Pencapaian

                          Kalau dimatiin, XP dan pencapaian tetap kecatat, cuma nggak ada pop-up. Cek di menu Pencapaian kapan aja.

                          Alarm gak bunyi pas layar mati?

                          Beberapa pabrikan (Huawei/Honor, Xiaomi, Oppo, Vivo, Samsung) menghentikan aplikasi di latar belakang demi hemat baterai, jadi alarm timer dan pengingat bisa telat atau gak muncul. Izinkan Readlify berjalan di latar belakang:

                          Huawei / Honor (termasuk MatePad)
                          1. Buka Pengaturan → Baterai → Peluncuran aplikasi (App launch).
                          2. Cari Readlify, lalu matikan Kelola otomatis.
                          3. Di jendela yang muncul, aktifkan Peluncuran otomatis, Peluncuran sekunder, dan Jalankan di latar belakang.
                          4. Di Pengaturan → Aplikasi → Readlify → Notifikasi, pastikan notifikasi diizinkan.
                          5. Di Android 12+ / HarmonyOS, izinkan juga Alarm & pengingat lewat tombol di kartu Pengingat di atas.

                          Readlify gak butuh layanan Google (GMS) maupun HMS, jadi jalan normal di perangkat Huawei tanpa Google Play. Pemasangan lewat berkas APK.

                          Xiaomi / Oppo / Vivo / Samsung
                          1. Xiaomi (MIUI/HyperOS): Pengaturan → Aplikasi → Kelola aplikasi → Readlify → Penghemat baterai → Tanpa batasan, dan aktifkan Mulai otomatis.
                          2. Oppo/Realme (ColorOS): Pengaturan → Baterai → Readlify → izinkan aktivitas di latar belakang, dan Mulai otomatis.
                          3. Vivo (Funtouch/OriginOS): Pengaturan → Baterai → Konsumsi daya latar belakang → Readlify → Izinkan.
                          4. Samsung (One UI): Pengaturan → Baterai → Batas penggunaan di latar belakang → keluarkan Readlify dari daftar Aplikasi tidur.
